AI switch

Off On Focus Disabled

MUI Switch in a FormControlLabel; the whole 44 px row is the hit area. The thumb moves sides, so state never rests on color. Track 40 × 22, thumb 16. Hover adds a 10% magenta halo behind the thumb.

Mute button

Sound on Hover Muted + focus

IconButton 44 × 44, icon 24. Accessible name stays “Mute”; aria-pressed carries the state (see copy notes). Waves versus a cross is the shape change. Press darkens the halo to 18%.

Volume slider

Default Focus Muted, disabled

MUI Slider, 0–1 in steps of 0.05, default 0.8, aria-label “Volume”. 88 px wide with a 44 px tall hit area (was 64). Muted keeps the value but empties the fill and hollows the thumb. Arrow keys step 0.05; Page keys 0.25.
