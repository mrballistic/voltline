VOLTLINE · LOGO PROPOSAL

One line, one jolt

The mark is a single continuous trace: a V whose right arm takes a voltage jog, ending in a circuit pad at each tip. It runs cyan to magenta, the same sweep as the level bar, and uses the outlined neon-glyph language of the pieces without borrowing any piece shape.

Voltline

Construction

100-unit grid. Stroke 8 with round caps and joins, pads r 6.5 with a 4.5 ring filled with the page color so the line reads as plugged in.

Path: 16,20 → 44,80 → 60,48 → 48,48 → 72,14. The jog is the only horizontal in the mark, so it stays legible down to 16 px.

Gradient runs left to right, #4dd8ff to #ff4fd8. Glow: blur 3.2 per 100 units merged under, the same recipe as the pieces.

Wordmark: Orbitron 700, the existing title style, tracked 0.14em at display sizes and 0.18em at 18 px.
